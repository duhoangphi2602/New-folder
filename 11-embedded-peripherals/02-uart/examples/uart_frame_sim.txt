 * @brief Conceptual visualization of transmitting the letter 'A' over UART.
 */

==================================================
1. THE DATA
==================================================
We want to transmit the ASCII character 'A'.
ASCII for 'A' is decimal 65.
Binary for 65 is: 0100 0001
UART transmits Least Significant Bit (LSB) first.
So the sequence to send is: 1, 0, 0, 0, 0, 0, 1, 0

==================================================
2. THE CONFIGURATION
==================================================
Baud Rate: 9600 bps
Data Bits: 8
Parity: None
Stop Bits: 1
(This is commonly abbreviated as "9600 8-N-1")

==================================================
3. THE PHYSICAL SIGNAL ON THE TX WIRE (Voltage over time)
==================================================

  IDLE      |START|       DATA BITS (LSB -> MSB)      |STOP |  IDLE
            | BIT | 1 | 0 | 0 | 0 | 0 | 0 | 1 | 0 (A) | BIT |
  3.3V -----+     +---+                           +---+-----+-----
            |     |   |                           |   |
            |     |   |                           |   |
  0.0V      +-----+   +---+---+---+---+---+---+---+   +

Timing: At 9600 baud, each bit lasts exactly 1 / 9600 = 104 microseconds.
Total time to send the letter 'A' = 10 bits * 104us = 1.04 milliseconds.
