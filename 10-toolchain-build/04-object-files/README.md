# Object Files (.o / .obj)

## What is this topic?
This topic analyzes the **Object File**, the binary output generated by the Assembler. Understanding what is inside an Object file is the key to understanding how the Linker works in the next stage.

## Why is it important?
When you compile 10 `.cpp` files, you get 10 `.o` files. These files contain raw machine code, but they are *not* executable. You cannot run `main.o` on a microcontroller. Understanding why they are not executable (due to unresolved symbols and relative memory) demystifies the entire build process.

## Prerequisites
- [03-assembly](../03-assembly/README.md)

## Learning Outcomes
1. Understand the internal structure of an Object File (Sections + Symbol Table).
2. Differentiate between Defined Symbols and Undefined Symbols.
3. Use the `nm` or `objdump` tools to inspect the contents of an Object file.
