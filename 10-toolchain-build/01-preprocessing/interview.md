# Interview Questions: Preprocessing

## 1. What is the fundamental difference between `#define MAX 10` and `const int MAX = 10;`?
**Answer:** `#define` is handled by the Preprocessor. It performs a literal text replacement before the compiler even runs. The compiler never sees the word "MAX", it only sees the number 10 injected everywhere. Macros have no memory address, no scope, and absolutely no type-safety. 
`const int MAX = 10;` is handled by the Compiler. It is a real C++ variable. It has a specific type (`int`), obeys scope rules (e.g., inside a specific namespace or function), and is type-checked by the compiler, making it significantly safer and easier to debug.

## 2. Explain how a Translation Unit is created.
**Answer:** A translation unit is the final, expanded text file generated by the Preprocessor (Stage 1 of the toolchain) and handed to the Compiler (Stage 2). It starts with a single `.c` or `.cpp` source file. The preprocessor resolves all `#include` directives by recursively copy-pasting the contents of those header files directly into the source file. It then strips out all comments and resolves all `#define` and `#ifdef` directives. A 50-line `.cpp` file that includes `<iostream>` might result in a 30,000-line translation unit.

## 3. Why are C++ `inline` functions generally preferred over C-style Macros (`#define`) for short utility functions?
**Answer:** Macros are prone to catastrophic text-expansion errors (like the missing parentheses problem or multiple-evaluation of arguments like `SQUARE(x++)`). Because macros bypass the compiler, they provide no type checking and cannot be easily debugged using a step-through debugger. C++ `inline` functions are real functions parsed by the compiler. They provide strict type safety, predictable argument evaluation, and proper scoping. The `inline` keyword hints to the compiler to substitute the function body directly at the call site to save function-call overhead, providing the exact same performance benefit as a macro but with 100% of the C++ safety guarantees.
