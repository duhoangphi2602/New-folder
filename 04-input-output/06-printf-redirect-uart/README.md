# Printf Redirection to UART

## What is this topic?
This topic explains the low-level mechanism of "Redirecting" or "Retargeting" the standard C `printf` function so that its output is physically transmitted over a hardware UART port.

## Why is it important?
By default, calling `printf("Hello");` on a bare-metal microcontroller does absolutely nothing. The standard C library has no idea what hardware it is running on. To make `printf` work, you must write a low-level "hook" function that catches the characters generated by `printf` and manually forwards them to your UART driver. Every professional embedded project implements this so developers can debug using standard `printf` statements.
