# 00 - Getting Started

Before diving into C++ and Embedded theory, you need a working environment. This section guides you through installing the necessary tools and compiling your first C/C++ programs for a PC.

While we will eventually cross-compile for an embedded target, we start by compiling natively on your host machine (Windows or Linux) to understand the build process.
