## Interview Strategy

When answering embedded software questions, follow this pattern:

```text
1. WHAT — Define the concept
2. HOW — Explain the mechanism
3. WHY — Justify its existence / purpose
4. EMBEDDED CONTEXT — RAM, Flash, CPU, timing implications
5. TRADE-OFFS — Advantages and disadvantages
6. WHEN TO USE / NOT USE — Practical judgment
```
