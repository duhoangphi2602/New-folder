# C++ Language (Ngôn ngữ C++)

## What is this topic?
Tổng quan về những gì C++ bổ sung so với C — Class, RAII, Template, Overloading, Exception, STL — và đánh giá chúng trong bối cảnh Embedded.

## Prerequisites
- [01-c-language](../01-c-language/README.md)

## Learning Outcomes
1. Liệt kê 6 tính năng C++ bổ sung so với C.
2. Đánh giá tính năng nào phù hợp Embedded, tính năng nào cần cẩn trọng.
3. Hiểu khái niệm "Zero-cost abstraction".
