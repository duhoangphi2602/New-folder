# C Language (Ngôn ngữ C thuần)

## What is this topic?
Tổng quan về ngôn ngữ C — ngôn ngữ nền tảng của mọi hệ thống Embedded — trước khi so sánh với C++ và C++17.

## Why is it important?
Mọi firmware trên thế giới, từ chip điều khiển lò vi sóng đến vệ tinh NASA, đều được viết bằng C hoặc có nền tảng từ C. Hiểu rõ C giúp bạn đánh giá chính xác những gì C++ và C++17 bổ sung, thay vì học một cách mù quáng.

## Prerequisites
- [01-program-structure](../../01-program-structure/README.md)
- [02-pointers-arrays](../../02-pointers-arrays/README.md)

## Learning Outcomes
1. Liệt kê 5 đặc trưng cốt lõi của C.
2. Giải thích vì sao C vẫn thống trị Embedded dù đã ra đời hơn 50 năm.
3. Nhận diện những hạn chế của C mà C++ được thiết kế để giải quyết.
