# C++17 Features cho Embedded

## What is this topic?
Tổng hợp tất cả tính năng C++17 quan trọng cho lập trình nhúng. Mỗi tính năng được phân tích theo format: Khái niệm → Code → Bối cảnh → Ưu/nhược/so sánh → Ở C có không.

## Danh sách tính năng (đọc theo thứ tự):
1. [constexpr.md](constexpr.md) — Tính toán tại compile-time
2. [if-constexpr.md](if-constexpr.md) — Rẽ nhánh tại compile-time
3. [optional.md](optional.md) — Giá trị có thể rỗng, type-safe
4. [variant.md](variant.md) — Type-safe union
5. [string-view.md](string-view.md) — Tham chiếu chuỗi không copy
6. [structured-binding.md](structured-binding.md) — Destructuring
7. [nodiscard.md](nodiscard.md) — Buộc kiểm tra return value
8. [noexcept.md](noexcept.md) — Cam kết không throw exception
9. [inline-variables.md](inline-variables.md) — Biến toàn cục trong header
10. [std-byte.md](std-byte.md) — Type-safe byte
11. [static-assert.md](static-assert.md) — Kiểm tra tại compile-time
12. [fold-expressions.md](fold-expressions.md) — Variadic template gọn gàng
